# 한국어 커밋 컨벤션

이 저장소의 커밋 메시지는 한국어 요약을 필수로 사용합니다.

## 형식

```text
type(scope): 한국어 요약
```

`scope`는 선택입니다.

```text
feat(figma): 디자인 토큰 동기화 기능 추가
fix(ui): 버튼 비활성 상태 색상 수정
docs: 커밋 컨벤션 문서 추가
```

## 타입

| 타입 | 용도 |
| --- | --- |
| `feat` | 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 |
| `design` | UI, 시각 디자인, Figma 산출물 |
| `token` | 디자인 토큰 |
| `style` | 포맷, 스타일만 변경 |
| `refactor` | 동작 변화 없는 구조 개선 |
| `test` | 테스트 |
| `chore` | 기타 관리 작업 |
| `ci` | CI/CD |
| `build` | 빌드 설정 |
| `perf` | 성능 개선 |
| `revert` | 되돌리기 |

## 규칙

- 제목에는 반드시 한글이 포함되어야 합니다.
- 제목은 `type: 요약` 또는 `type(scope): 요약` 형태여야 합니다.
- 제목 끝에 마침표를 붙이지 않습니다.
- 제목은 72자 이하를 권장합니다.
- 본문은 필요한 경우 한국어로 작성합니다.

## 예외

Git이 자동으로 만드는 `Merge ...`, `Revert ...`, `fixup! ...`, `squash! ...` 커밋은 검사에서 제외합니다.
